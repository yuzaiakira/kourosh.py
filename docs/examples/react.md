# React and TypeScript application

Use the generated project for a typed frontend:

```sh
kourosh create react-notes --ui react --typescript
cd react-notes
npm install
npm run typecheck
kourosh frontend build
```

The template includes a local SDK, `public/kourosh-bridge.js`, a Vite config,
and a Python `greet` method. See the complete [React tutorial](../frontend/react-typescript.md)
for development, hot reload, error handling, and production assets.
