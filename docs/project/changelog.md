# Changelog

The current alpha is unreleased. The source-tree changelog records the
implemented runtime, SDK, CLI, bridge, packaging, benchmark, and documentation
work:

- Python SDK `0.1.0a1` and browser SDK `0.1.0-alpha.1`.
- Protocol version 1 with default-deny asynchronous RPC.
- Vanilla and React/TypeScript templates with a local vendored SDK.
- Local release checks, deterministic source archive, and Windows staging.
- Windows GUI, WebView2, installer, signing, and clean-machine validation
  remain pending.

Read the repository [CHANGELOG.md](https://github.com/yuzaiakira/kourosh.py/blob/work/CHANGELOG.md)
and [alpha release notes](https://github.com/yuzaiakira/kourosh.py/blob/work/RELEASE_NOTES_ALPHA.md)
for the full source-tree history.
